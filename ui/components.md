# UI Components

## Core Components

- **Top Bar:** Logo, fund selector, search, user profile.
- **Exception Cards:** Summary of counts by type (calls, distributions, fees, docs).
- **Exception Table:** Tabular list of exceptions with severity and actions.
- **PDF Viewer:** Embedded document viewer with page thumbnails and zoom.
- **Extraction Sidebar:** Structured fields extracted from documents.
- **Clause Viewer:** Raw clause text + structured representation.
- **Variance Table:** GP vs expected vs allocator books.
- **Workflow Timeline:** Status progression for each exception.
- **Integration List:** Connected systems and their status.

## States

- **Severity Badges:** High, Medium, Low.
- **Status Badges:** Unreviewed, In Review, Approved, Rejected.
- **Confidence Indicators:** Extraction confidence (e.g., 0–100%).
