# User Flows

## Flow 1: Daily Exception Triage

1. User lands on **Dashboard**.
2. Reviews exception cards and filters the **Exception Table**.
3. Clicks an exception → navigates to **Exception Review**.
4. Reviews expected vs actual, evidence, and comments.
5. Takes an action: Approve, Reject, Request clarification, Assign.
6. Exception status updates and appears in **Approval Workflow**.

## Flow 2: Document-Based Investigation

1. From Exception Review, user opens **Document Viewer**.
2. Reviews highlighted fields and extraction sidebar.
3. Toggles provenance to see source clauses.
4. If needed, opens **LPA / Side Letter Canonicalization**.
5. Adjusts structured terms and recomputes expected values.
6. Returns to Exception Review to finalize decision.

## Flow 3: Periodic Reconciliation

1. User opens **Reconciliation** screen.
2. Filters by fund, GP, date range.
3. Reviews variance table and charts.
4. Drills into specific variances → Exception Review.
5. Marks items resolved or escalates.

## Flow 4: Setup & Integrations

1. Admin opens **Settings / Integrations**.
2. Connects accounting and portfolio systems.
3. Configures roles and permissions.
4. Enables SSO and API keys.
