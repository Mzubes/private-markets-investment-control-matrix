# Screen: Settings / Integrations

## Purpose
Configure integrations, roles, and security.

## Layout

- **Integrations**
  - Allvue
  - Juniper Square
  - QuickBooks
  - Sage
  - Snowflake.
  - Each with status (Connected / Not Connected) and config button.

- **API & Security**
  - API keys (create, revoke).
  - Webhook endpoints.
  - Audit logs.

- **User Management**
  - Users list.
  - Roles (Admin, Reviewer, Viewer).
  - SSO configuration.
