# Screen: Exception Review

## Purpose
Allow the allocator to understand a discrepancy and decide whether to approve, reject, or escalate.

## Layout

- **Header**
  - Exception ID
  - Fund name
  - GP name
  - Timestamp
  - Severity badge

- **Left Panel – Expected vs Actual**
  - Expected amount
  - Actual amount
  - Variance
  - Link to LPA clause and side letter terms.

- **Center Panel – Evidence**
  - Embedded document viewer (call notice).
  - Highlighted extracted fields.
  - "Show provenance" toggle.
  - "Compare to last call" button.

- **Right Panel – Actions**
  - Approve
  - Reject
  - Request GP clarification
  - Add comment
  - Assign to teammate.
