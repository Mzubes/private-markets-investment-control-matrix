# Screen: Reconciliation

## Purpose
Compare GP-reported numbers vs allocator books and highlight variances.

## Layout

- **Variance Table**
  - Columns: Field, GP Value, Expected Value, Allocator Value, Variance, Status, Notes.

- **Charts**
  - Variance over time.
  - Commitment remaining.
  - Fee accrual trend.

- **Actions**
  - Drill into variance → Exception Review.
  - Mark as resolved or escalate.
