# Screen: Dashboard – Today's Exceptions

## Purpose
Give allocators a single view of what needs attention: capital call mismatches, distribution variances, fee irregularities, missing documents.

## Layout

- **Top Bar**
  - Logo
  - Fund selector dropdown
  - Global search
  - User profile menu

- **Main Content**
  - **Exception Summary Cards**
    - Capital Call Mismatches
    - Distribution Variances
    - Fee Irregularities
    - Missing Docs
  - **Exception Table**
    - Columns: Fund, GP, Type, Severity, Expected vs Actual, Status, Actions.
    - Row action: "Review" → Exception Review screen.

- **Right Sidebar**
  - Recent capital calls
  - Upcoming deadlines
  - GP activity feed.
