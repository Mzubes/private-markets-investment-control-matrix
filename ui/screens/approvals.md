# Screen: Approval Workflow

## Purpose
Track who approved what, when, and why, with a clear audit trail.

## Layout

- **Task List**
  - Exception ID
  - Fund
  - Assigned to
  - Due date
  - Status.

- **Workflow Timeline**
  - Extracted → Flagged → Reviewed → Approved/Rejected → Posted.

- **Audit Trail**
  - Event log (user, action, timestamp).
  - Evidence snapshots.
  - Version history of decisions.
