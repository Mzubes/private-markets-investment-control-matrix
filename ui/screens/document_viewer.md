# Screen: Document Viewer + Extraction Overlay

## Purpose
Show the raw GP document with extracted fields overlaid for transparency and trust.

## Layout

- **PDF Viewer**
  - Page thumbnails
  - Zoom controls
  - Text highlights for key fields.

- **Extraction Sidebar**
  - Capital call amount
  - Due date
  - Bank details
  - Fee components
  - Commitment remaining
  - GP signature.

- **Provenance Controls**
  - "Show extraction source"
  - Confidence score per field.
