# Investment Control UI – High-Level Mockup

This document describes the allocator-facing UI for an Investment Control / Capital Call Verification platform.

## Screens

- Dashboard – "Today's Exceptions"
- Exception Review
- Document Viewer + Extraction Overlay
- LPA / Side Letter Canonicalization
- Reconciliation
- Approval Workflow
- Settings / Integrations

Each screen is detailed in `screens/*.md`. Components are defined in `components.md`. User flows are in `flows.md`.
